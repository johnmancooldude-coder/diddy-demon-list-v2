# V2.4.4 — DIDDY ERAS 3.0

Diddy Eras now reconstruct sustained historical chapters from real placement-history and victory activity.

- Automatically clusters era-defining days.
- Names eras around the dominant player when one is clear.
- Shows date span, days, victories, #1-level victories, era points, ranking events, and active levels.
- Uses historical level placement when available for victory-era statistics.
- Keeps older eras visible and preserves the existing Eras page.
- Seasons are intentionally excluded.
- No new Supabase tables or SQL required.
