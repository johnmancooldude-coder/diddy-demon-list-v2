# DIDDY DEMON LIST V2.5.0 — THE DIDDY ASCENSION

Major platform update built on V2.4.5.

## Added
- Player Intelligence 2.0: official rank, Pure Skill rank, rank/points history, career metrics, skill DNA, achievements, timeline, and battle shortcut.
- Player Battles 4.0: official rank + Pure Skill + victories + hardest victory + average placement + consistency/depth/speed/momentum with a final skill verdict.
- Diddy Record Book: automatic global records and searchable victory records.
- Time Machine 3.0: historical list reconstruction plus player rankings calculated from victories at the selected date.
- Diddy News 3.0: automatic victory and placement news generated from existing records/history, plus published news.
- Hall of Fame expansion: automatic legends based on Pure Skill, hardest victories, and career performance.
- Homepage Ascension Intelligence Center.
- V2.5 responsive/mobile UI polish.

## Preservation rules
- No Seasons.
- Existing ranking engine preserved.
- Existing Supabase schema preserved; V2.5 adds no required SQL migration.
- Existing achievements, simulator, eras, pure skill, activity, health, power, challenges, search, level pages, admin tools, and changelog remain.
- Existing `config.js` is intentionally not bundled into this update package; keep the copy already in the GitHub repo.
- `release-notes.js` keeps prior releases and adds V2.5.0 at the top.
