# DIDDY DEMON LIST V2.4.5 — PURE SKILL

## Added
- New public **🥇 Pure Skill** tab.
- Pure Skill is completely separate from official points and rankings.
- Admin-only manual ranking editor.
- Add/remove players from the skill list.
- Exact skill-rank editing with automatic sequential normalization on save.
- Skill tiers: GOAT, ELITE, INSANE, VERY GOOD, STRONG, SOLID.
- Optional “Why they're here” notes.
- Public cards show official rank alongside Pure Skill rank.
- Player profiles show Pure Skill placement when a player is ranked.

## Supabase
Run `v2_4_5_pure_skill.sql` once in the Supabase SQL Editor. The patch is additive and does not modify the official ranking engine.
